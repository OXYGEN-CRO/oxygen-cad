# Process-specific review

Use actual shop/tooling specifications. Fetch and cite current supplier guidance (for example https://www.protolabs.com/resources/design-tips/ or https://www.xometry.com/resources/) only for the process/material being considered. No fixed shop capabilities are embedded in this skill.

## CNC

Review stock/fixture datums, tool reach and access, minimum internal radius versus available cutter, hole/thread specification, thin walls, depth/diameter, tolerances and setup count. Exact circular-edge radii are facts; their manufacturing role and cutter accessibility need separate evidence. Keep cost suggestions separate from hard process limits.

## Sheet metal

Confirm nominal stock, tool bend radius, bend allowance/K-factor source, local flange length, reliefs, hole/slot-to-bend distances, grain direction and finish/hardware service order. A constant thickness inferred at one location is not a general sheet classification. A horizontal DXF section is not an unfolded bent blank. Review the actual flat pattern in a capable tool.

## Injection molding

Select resin/tooling, pull and parting intent. Review side-wall draft, true undercuts and side actions, thickness transitions/ribs/bosses, shutoffs, gating/ejection, texture, shrinkage and tolerances. The mesh helper's pull-occlusion and side-slope data are screening candidates. Neither a projected bounding rectangle nor a screen finding establishes mold fill, clamp tonnage or tooling feasibility. Use a real process/tooling review or simulation when required.

For each item retain measured geometry, supplied inputs and unmeasured checks separately. Do not infer material, density or strength from a viewport colour.
